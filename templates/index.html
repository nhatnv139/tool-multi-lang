Lấy key free: portal.azure.com → tạo "Speech service" (free F0) → Keys and Endpoint.

Lấy key free: aistudio.google.com → Get API key. 1 giọng đọc được cả tiếng Trung + Việt; tốc độ chỉnh bằng thanh "Tốc độ đọc" ở trên.

Bấm Quét người nói → tool tự tìm các nhân vật (A, B, C, D…) trong phần HỘI THOẠI và sinh ô nhập Voice ID cho từng người. Bỏ trống người nào thì người đó dùng giọng mặc định.
